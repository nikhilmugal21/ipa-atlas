Optional locally imported resources are placed here. No PHOIBLE data, IPA audio,
or IPA chart artwork is bundled with this project.

Install PHOIBLE data with `python scripts/import_phoible.py /path/to/phoible.csv`.
The development CSV is documented at https://github.com/phoible/dev/tree/master/data
Use an appropriately licensed pinned/released dataset for reproducible research.
